- Optional server network simulation (2026-10-05): `-ping <ms>` adds RTT, split across both gameplay packet directions; `-jitter <ms>` adds random per-direction variance with nonnegative delay. Both default to zero and accept 0–10000 whole milliseconds. `ArenaServerNetworkSimulation` installs a scoped UnityTransport driver constructor and preserves its settings/pipelines, explicitly adding the simulator stage in release builds. Applies to every direct room/client and cloud allocations; no protocol change or client rebuild is needed for these options. Handshakes, heartbeats and cloud HTTP calls are outside the gameplay simulator. See `Docs/Networking.md` for buffer/timeout limitations.
